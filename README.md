# PhishNet

PhishNet is an educational phishing email detector built with HTML, CSS, and JavaScript.

Paste an email, SMS, or message to:

- Detect urgent and threatening language
- Flag suspicious links and unusual domains
- Identify requests for sensitive information
- Highlight suspicious phrases
- Generate an explainable phishing risk score

All analysis runs locally in the browser. Messages are not uploaded or stored.

## Run locally

Open `index.html` in a browser or serve the folder with any static web server.

## Disclaimer

PhishNet is an awareness tool, not a guarantee that a message is safe. Verify important messages independently through a trusted channel.
